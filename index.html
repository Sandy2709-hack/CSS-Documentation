Introduction to CSS
  1. What is CSS?

    2. CSS (Cascading Style Sheets) is a stylesheet language used to control the appearance and layout of web pages. While HTML provides the structure and content of a webpage, CSS determines how that content looks, including colors, fonts, spacing, borders, positioning, and animations. CSS helps make websites visually appealing and easier to use.

  2. Why CSS Exists

    3. Before CSS was introduced, web developers had to use HTML tags and attributes to style pages, which made code messy and difficult to maintain. CSS was created to separate a webpage's content from its presentation. This separation makes websites easier to design, update, and maintain. A single CSS file can control the appearance of multiple pages, saving time and reducing code duplication.

  3. HTML vs CSS vs JavaScript

    4. HTML, CSS, and JavaScript are the three core technologies of web development. HTML creates the structure and content of a webpage, such as headings, paragraphs, images, and links. CSS styles that content by controlling its appearance and layout. JavaScript adds interactivity and dynamic behavior, such as responding to button clicks, validating forms, or updating content without reloading the page. Together, they form the foundation of modern websites.

  4. Inline CSS

    5. Inline CSS is written directly inside an HTML element using the style attribute. It affects only the specific element where it is applied. Inline CSS is useful for quick styling or testing, but it is generally not recommended for large projects because it makes code harder to maintain and reuse.

    ___

  5. Internal CSS

    6. Internal CSS is written inside a <style> tag within the <head> section of an HTML document. It allows styles to be applied to multiple elements on the same page. Internal CSS is useful when a webpage has unique styles that are not shared with other pages.

    ___

  6. External CSS

    7. External CSS stores styles in a separate .css file and links it to HTML using the <link> tag. This is the most commonly used method because it keeps HTML clean, allows style reuse across multiple pages, and makes website maintenance easier.

    ___

  7. CSS Syntax

    8. CSS rules consist of a selector and a declaration block. The selector identifies which HTML elements will be styled, while the declaration block contains one or more properties and values enclosed in curly braces. Each property_value pair ends with a semicolon.

    ___

  8. Comments

    9. Comments in CSS are used to add notes or explanations within the code. They are ignored by the browser and do not affect how the webpage is displayed. Comments help improve code readability and make it easier for developers to understand or maintain the stylesheet.

    ___

CSS Selectors
  1. Universal Selector

    2. The universal selector (*) targets all elements on a webpage. It applies the specified styles to every element, making it useful for resetting default browser styles or applying a common style across the entire site. However, it should be used with caution as it can lead to performance issues if overused.

  2. Element Selector

    3. The element selector targets all instances of a specific HTML element. For example, the selector "p" would apply styles to all <p> (paragraph) elements on the page. This is one of the most basic and commonly used Selectors in CSS.

  3. Class Selector

    4. The class selector targets elements with a specific class attribute. It is denoted by a period (.) followed by the class name. For example, ".button" would apply styles to all elements with the class "button". Class Selectors are versatile and allow for styling multiple elements without affecting others.

  4. ID Selector

    5. The id selector targets a single element with a specific id attribute. It is denoted by a hash symbol (#) followed by the id name. For example, "#header" would apply styles to the element with the id "header". ID Selectors are unique and should be used sparingly.

  5. Grouping Selectors

    6. Grouping Selectors allow you to apply the same styles to multiple elements by separating them with commas. For example, "h1, h2, h3" would apply the same styles to all <h1>, <h2>, and <h3> elements.

  6. Descendant Selector

    7. The descendant selector targets elements that are descendants of a specified element. It is denoted by a space between two Selectors. For example, "div p" would apply styles to all <p> elements that are inside a <div> element.

  7. Child Selector

    8. The child selector targets direct child elements of a specified parent element. It is denoted by the greater_than symbol (>). For example, "div > p" would apply styles to all <p> elements that are direct children of a <div> element.

  8. Adjacent Sibling Selector

    9. The adjacent sibling selector targets an element that is immediately preceded by a specified sibling element. It is denoted by the plus symbol (+). For example, "h2 + p" would apply styles to the first <p> element that comes immediately after an <h2> element.

  9. General Sibling Selector

    10. The general sibling selector targets elements that are siblings of a specified element, regardless of their position. It is denoted by the tilde symbol (~). For example, "h2 ~ p" would apply styles to all <p> elements that come after an <h2> element.

  10. Attribute Selectors

    11. Attribute Selectors target elements based on their attributes and values. They are denoted by square brackets [] surrounding the attribute and its value. For example, "a[href]" would apply styles to all <a> elements that have an "href" attribute.

  11. Pseudo Classes

    12. Pseudo classes target elements based on their state or position in the document tree. They are denoted by a colon (:) followed by the pseudo class name. For example, "a:hover" would apply styles to a link when the user hovers over it.

  12. Pseudo Elements

    13. Pseudo elements target specific parts of an element, such as the first line of a paragraph or the content before an element. They are denoted by a double colon (::) followed by the pseudo element name. For example, "p::first_line" would apply styles to the first line of each paragraph.

  13. Specificity

    14. Specificity determines which CSS rule is applied when multiple rules could apply to the same element. It is calculated based on the number of ID Selectors, class Selectors, and element Selectors in a rule.

  14. !important

    15. The !important declaration overrides other CSS rules and forces a style to be applied regardless of specificity. It should be used sparingly as it can make debugging more difficult.

Colors & Backgrounds
  1. Named Colors

    2. Named colors are predefined color names that can be used in CSS. Examples include "red", "blue", "green", "black", and "white". There are 140 named colors in total, and they provide a convenient way to specify colors without needing to remember hex codes or RGB values.

  2. HEX

    3. HEX color values are a way to represent colors using hexadecimal notation. They consist of a hash symbol (#) followed by six hexadecimal digits, where the first two digits represent red, the next two represent green, and the last two represent blue. For example, #FF0000 represents red, #00FF00 represents green, and #0000FF represents blue.

  3. RGB

    4. RGB color values specify colors using the red, green, and blue color channels. Each channel can have a value from 0 to 255, where 0 means no contribution of that color and 255 means full intensity. For example, rgb(255, 0, 0) represents red, rgb(0, 255, 0) represents green, and rgb(0, 0, 255) represents blue.

  4. RGBA

    5. RGBA color values are an extension of RGB that includes an alpha channel for opacity. The alpha value can range from 0 (fully transparent) to 1 (fully opaque). For example, rgba(255, 0, 0, 0.5) represents a semi_transparent red.

  5. HSL

    6. HSL color values specify colors using hue, saturation, and lightness. Hue is represented as an angle from 0 to 360 degrees, where 0 is red, 120 is green, and 240 is blue. Saturation is a percentage that represents the intensity of the color, where 0% is gray and 100% is full color. Lightness is also a percentage that represents how light or dark the color is, where 0% is black and 100% is white. For example, hsl(0, 100%, 50%) represents red.

  6. HSLA

    7. HSLA color values are an extension of HSL that includes an alpha channel for opacity. The alpha value can range from 0 (fully transparent) to 1 (fully opaque). For example, hsla(0, 100%, 50%, 0.5) represents a semi_transparent red.

  7. background_color

    8. The background_color property sets the background color of an element.

  8. background_image

    9. The background_image property sets the background image of an element.

  9. background_repeat

    10. The background_repeat property controls how a background image is repeated. It can be set to "repeat" (default), "no_repeat", "repeat_x", or "repeat_y".

  10. background_position

    11. The background_position property sets the starting position of a background image.

  11. background_size

    12. The background_size property controls the size of a background image.

  12. background_attachment

    13. The background_attachment property controls whether a background image scrolls with the content or is fixed in place.

  13. Linear Gradients

    14. Linear gradients create a gradual transition between two or more colors along a straight line. They are defined using the linear_gradient() function, which takes color stops and an optional direction as parameters.

  14. Radial Gradients

    15. Radial gradients create a gradual transition between two or more colors from a central point. They are defined using the radial_gradient() function, which takes color stops and an optional center position as parameters.

  15. Conic Gradients

    16. Conic gradients create a gradual transition between two or more colors around a central point. They are defined using the conic_gradient() function, which takes color stops and an optional center position as parameters.

Typography
  1. font_family

    2. The font_family property specifies the typeface for text. It can include a list of font names as a fallback mechanism, where the browser will use the first available font.

  2. Google Fonts

    3. Google Fonts is a free library of web fonts that can be easily integrated into websites. It offers a wide variety of font styles and weights, allowing developers to enhance the typography of their sites.

  3. font_size

    4. The font_size property sets the size of the text. It can be specified using various units, such as pixels (px), ems (em), rems (rem), percentages (%), and viewport units (vw, vh).

  4. font_weight

    5. The font_weight property sets the thickness of the text. It can be specified using keyword values like "normal" and "bold", or numeric values from 100 to 900.

  5. font_style

    6. The font_style property sets the style of the text. It can be set to "normal", "italic", or "oblique".

  6. font_variant

    7. The font_variant property sets the variant of the text. It can be set to "normal" or "small_caps".

  7. text_align

    8. The text_align property sets the horizontal alignment of the text. It can be set to "left", "right", "center", or "justify".

  8. text_decoration

    9. The text_decoration property sets the decoration for the text. It can be set to "none", "underline", "overline", or "line_through".

  9. text_transform

    10. The text_transform property sets the transformation for the text. It can be set to "none", "capitalize", "uppercase", or "lowercase".

  10. text_shadow

    11. The text_shadow property adds shadow to text. It takes values for horizontal and vertical offsets, blur radius, and color.

  11. line_height

    12. The line_height property sets the height of a line of text. It can be specified as a unitless number (e.g., 1.5) or using various units (e.g., pixels, ems).

  12. letter_spacing

    13. The letter_spacing property sets the space between characters in text. It can be specified using various units (e.g., pixels, ems).

  13. word_spacing

    14. The word_spacing property sets the space between words in text. It can be specified using various units (e.g., pixels, ems).

  14. text_indent

    15. The text_indent property sets the indentation of the first line of text. It can be specified using various units (e.g., pixels, ems).

  15. text_overflow

    16. The text_overflow property specifies how to handle content that overflows its container. It can be set to "clip" (default), "ellipsis", or "inherit".

Units & Measurements
  1. px

    2. Pixels (px) are the most commonly used unit for specifying sizes in CSS. They represent the actual pixels on the screen.

  2. cm

    3. Centimeters (cm) are a metric unit of length. They are less commonly used in web development.

  3. mm

    4. Millimeters (mm) are a metric unit of length. They are also less commonly used in web development.

  4. in

    5. Inches (in) are a unit of length commonly used in print design. They are less commonly used in web development.

  5. %

    6. Percentages (%) are a relative unit of measurement. They are often used to specify sizes relative to their parent element.

  6. em

    7. The em unit is a relative unit of measurement based on the font size of the element. 1em is equal to the current font size.

  7. rem

    8. The rem unit is similar to em, but it is relative to the root element (html) rather than the parent element.

  8. vw

    9. The vw unit represents a percentage of the viewport width. 1vw is equal to 1% of the viewport width.

  9. vh

    10. The vh unit represents a percentage of the viewport height. 1vh is equal to 1% of the viewport height.

  10. vmin

    11. The vmin unit represents a percentage of the smaller dimension of the viewport. 1vmin is equal to 1% of the smaller dimension.

  11. vmax

    12. The vmax unit represents a percentage of the larger dimension of the viewport. 1vmax is equal to 1% of the larger dimension.

The CSS Box Model
  1. Content Area

    2. The content area is the innermost part of the box model where the actual content of the element is displayed.

  2. Width

    3. The width property sets the width of the content area of an element.

  3. Height

    4. The height property sets the height of the content area of an element.

  4. Padding

    5. The padding property sets the space between the content and the border of an element.

  5. Border

    6. The border property sets the border around the padding and content of an element.

  6. Border Radius

    7. The border_radius property sets the radius of the corners of an element's border.

  7. Margin

    8. The margin property sets the space around an element's border.

  8. box_sizing

    9. The box_sizing property determines how the width and height of an element are calculated.
